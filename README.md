# Pure Practice · P1 / P2 / P3

网站：https://future2025shenzhen.github.io/pure-maths-library/

当前原创题库：第7版，750道实质改编题，25个主章节各30题。题目英文、答案中文、逐题有2024年前真题考法参照及改编说明，配图重绘。另有33套2020—2023年原卷、323道原题及官方答案，原图原页保持不变。

运行：安装Node.js后，在项目目录执行 `npm start`，打开 http://localhost:4173 。检查执行 `npm run check` 和 `npm test`。前端不需安装依赖；已配置的云端账户需联网。

数据：`dist/data/bank.json`（原创题）、`dist/data/past-bank.json`（真题）、`dist/data/classification.json`（检索分类）。第7版分章源稿及核查记录见 `editorial/v7/`。账户与管理员开通说明见 `backend/README.md`。

新题库保留题号与历史收藏/已做状态；旧已做不代表已完成新题。所有核查为内部复核，未完成外部教师逐题审阅。网站不提供在线作答或自动判分。
