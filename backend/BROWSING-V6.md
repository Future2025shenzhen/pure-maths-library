# 分类与浏览调整

1073道题均有P1/P2/P3阶段与章节索引。真题保留原有323题分类，其中175题涉及多个章节；原创题补充75道题的同阶段关联章节。该索引独立位于dist/data/classification.json，不改动题号、原题图像、题面或标准答案。章节以教材目录为准；原创题原始章节用于题册编排，关联章节用于搜索浏览。

本轮不新增或重写题目，不宣称完成全部题目的重新学术审查。后续原创修订可以借鉴真题的设问动词、证明目标与分问依赖，保持题目内容有实质区别。

章节按钮点击即单选，右侧复选框用于多选，另有全选和清空。考查章节与知识点放在答案区，题目区不展示提示。移除宣传文案与修订横幅，下载题册折叠收纳。手机真题筛选默认折叠。

math-format.js仅在数学分隔符内转换明确的简单分数、dy/dx与显示样式。保留无法确定分组的复杂斜杠式。原卷图片/PDF不做任何修改；离线题册PDF未在本轮重新排版。

验证：npm run check、npm test、node scripts/check-browsing.mjs；另有21项本地浏览器交互检查通过。浏览器测试禁用云端配置以隔离新浏览功能，不能据此推断真实Supabase已验证。
