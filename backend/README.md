## 最少开通步骤（由项目所有者操作）

1. 在 https://supabase.com/dashboard 创建专用于本题库的 Free 项目。数据库密码由你自己设置并保存，不要发送给别人。可选靠近用户的区域；国内访问需要实际测试。
2. 在 Authentication 的 Email 登录设置中保留 Email provider，**关闭 Confirm email**，允许新用户注册；将最低密码长度设为 **12**。本应用对用户提供昵称/密码表单，内部把规范化昵称的 SHA-256 映射到保留域名的账户标识，**不发送邮件**。请不要把此方案混用于已有其他用户体系的项目。
3. 在 SQL Editor 执行 `001-accounts.sql`，再执行 `002-question-catalog.sql`。也可一次执行交付包中的合并版 `初始化数据库.sql`。这将建立表、行级隔离、受限接口及1093个正式题号（含第8版20道提高题）。
4. 复制项目的 **Project URL** 和 **publishable key**（旧项目可用 anon 公共密钥），填入 `dist/account-config.json`，将 enabled 改为 true。此两项是前端公开配置，不是数据库密码。**绝不能填写 service_role、sb_secret、数据库密码或个人访问令牌。** 本项目也不需要这些私密密钥。
5. 发布到 GitHub Pages。打开 `account.html` 注册自己的昵称和密码；随后在 SQL Editor 执行 `003-grant-admin.sql`，替换其中的昵称为自己刚注册的昵称。普通注册者不会自动成为管理员。重新登录后在个人账户进入管理员后台。

你也可以在完成1—3后，只把 Project URL 和 publishable/anon 公共密钥发给网站维护者代填配置并发布；无需发送私密凭证。

## 用户流程

- 启用后，原创题库与真题浏览界面要求登录。
- 收藏、手动已做和当前原创练习卷保存到当前账户；切换设备后重新读取同一份数据。无在线作答/自动判分，“已做”不代表答对。
- 已登录用户可以修改密码、导出个人记录。
- 旧本机记录不会自动导入；在账户页主动选择“导入这台设备的旧记录”并确认归属后，按合并方式上传。
- 另一设备修改相同记录后，过期版本会被拒绝并重新读取；网络失败不会显示成功同步。
- 账户昵称是固定登录名，不区分英文字母大小写，支持2—20个中文、英文字母、数字或下划线。

## 管理员能看到什么

`admin.html` 显示昵称、注册时间、最近活动、累计页面访问次数、最近设备类别、已做/收藏数量，以及每个账户最近200条访问/查看解析/阅读资料活动。累计访问次数不因详细记录裁剪而清零。重复页面事件在15秒内去重；可见页面每分钟发送一次活跃心跳。

这是登录后浏览器上报的学习活动统计，不是不可篡改的服务器请求审计。管理员不能查看密码。本版不提供用户封禁、删除或代改密码功能。

## 密码和账户恢复

密码由 Supabase Auth 处理，本项目不创建密码字段、不保存明文密码、不让管理员读取密码。昵称内部标识不是用户可收信的真实邮箱，因此本版不提供邮件自动找回。已登录用户可凭当前密码修改；遗忘密码时由项目所有者通过受控的 Supabase 管理工具协助恢复，并自行核验身份。不要在公共网页加入服务端管理员密钥来实现重置。

## 访问边界

GitHub Pages 与代码仓库当前公开，登录限制保护账户记录与界面流程；**不能把公开仓库中的题库JSON/PDF变成机密资料**。账户记录由数据库权限隔离。若将来需要未登录者连题面文件都无法下载，必须改用可鉴权的内容服务器及私有仓库/存储。

前端不依赖 chatgpt.site。账户启用后还需要浏览器能访问配置的 Supabase API；GitHub Pages成功不代表国内到数据库的连接一定稳定，需用国内手机/电脑实测。

## 数据与权限

- pp_profiles：昵称和访问汇总；无密码字段。
- pp_admins：管理员名单，只能由项目所有者通过SQL管理。
- pp_question_catalog：题号白名单；防止提交虚构题号污染进度。
- pp_records：user_id + question_id 唯一，带乐观并发版本。
- pp_practice_papers：每人当前一份练习卷及版本。
- pp_activity：有限数量的最近活动。

所有业务表启用RLS；浏览器角色无直接写权限。写入接口从auth.uid()确定用户，不接收可替换的用户ID。管理员接口在数据库检查pp_admins，隐藏前端按钮不是权限依据。普通用户可以直接读取自己的资料和记录，无法读取其他人的记录。
