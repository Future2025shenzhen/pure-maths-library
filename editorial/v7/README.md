# 第7版原创实质改编题库

2026-10-19。P1共9章270题，P2/P3各8章240题，共750题；每个主章节30题。答案区标注2024年前真题考法参照（真实原题ID、年份、考季）及具体改编说明，不冒称当年考试原题。原卷题面/图片/PDF保持不变。

`chapters/`为按章源数据，`dist/data/bank.json`为网站汇总数据；页面逻辑不含题目内容。每题主章节为chapters数组第一项，附加章节用于综合题检索。figureSvg为新绘图，集成到题干；详细知识点及来源在答案区展示；第8版起完整章节范围另在题头显示。

本轮以三问为主，少量两问/四问、共享条件(i)(ii)。题型蓝图与独立检查见research/；release-manifest.json给出实际数量，不用随机参数模板补量。数学检查包括符号计算、数值复算、分支与定义域检查，以及代理之间的交叉复核；这些不等于外部教师逐题审定。

原题号保留以兼容既有云端收藏。旧已做标记不会自动删除，但不代表用户已做过本版新题；可手动取消后重做。本版未改账户权限，不需要重新初始化数据库。

25本分章题册和3本阶段题册均由本版数据重新生成。整卷真题阅读器支持手动开始/暂停/继续/归零的正计时；关闭阅读器暂停。同一试卷与答案共用计时，不同试卷分开，当前标签页刷新后保留已暂停的用时；计时不上传云端。

未来新增题号时需由项目所有者同步更新后端pp_question_catalog；仅修改现有题号内容不需新增白名单。

## 本地维护

直接编辑dist/data/bank.json可修改网站题目。若按分章源稿维护，编辑editorial/v7/chapters/*.json后运行 `python3 scripts/build-v7-bank.py` 汇总，再执行 `npm run check` 与 `npm test`。

重建PDF为可选开发步骤，需Python的playwright、pymupdf及Chromium。在另一个终端保持 `npm start` 运行，然后执行 `python3 scripts/print-v7-books.py`；文件输出到exported-v7并更新网站题册。网站日常运行不需要Python或这些包。
