# 第8版：重点章节提高题

保留第7版750道原创题的内容和ID，新增P3第6章微分10道、P3第7章积分5道、P2第7章微分5道。其余章节不统一加难。每章原有30题继续保留。

提高题并非更高阶段内容：只使用对应P1/P2/P3教材范围，以递进设问、证明、条件选择、图像及多章节联系提高思考量。题头显示所有关联章节；详细考点、真实的2024年前考法参照及实质改编说明保留在答案区。搜索“提高题”可定位新增题。
