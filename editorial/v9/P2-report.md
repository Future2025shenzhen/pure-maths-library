# P2 第9版解析呈现及小幅措辞修订

## 交付

- `P2-editorial.json`：245道完整P2原创题，含755个实际作答叶子小问。
- 每个叶子小问新增中文 `approach` 与按顺序排列的 `solutionSteps`，保留原 `answer`、`explanation`、`scheme`、条件、分值、配图、来源、题号及第7/8版内容元数据。
- `P2-wording-changes.json`：14处轻微英文措辞变化的精确before/after记录，不改变条件、问题目标或难度。

## 处理方式与范围

按实际设问选取方法说明：余式/因式、穷举与反例、圆的切线和弦、对数真数与舍根、二项式索引、数列区段和与相邻部分和、三角定义域与漏解、导数符号与优化、梯形加权与变形面积等。

已有解析的数学计算是事实来源。对其保留数学内容、去除早期的泛化引导语，将推理按等式建立、计算、范围/结论的顺序分开；最终结论只在原推理缺少结论时补列。没有用统一“代入/化简/验算”三句凑步数。较短的一步计算保留1个实质步骤，另有中文方法说明，不刻意把它拆成空泛的2步。

另逐条补写33个重点叶子小问，覆盖：

- 多项式参数与唯一实根、平方根输入的舍根；
- 对数方程先定义域后舍根；
- P2数列首项/公差与整数阈值，部分和差得到通项/区段和；
- 梯形规则的条宽、内点权重，后问函数变形的面积公式及误差反向；
- 有向积分与几何面积、唯一面积分割、原函数常数、总竖直变化；
- 5道新增提高题中较长的平方量优化、双切点面积、两瓣面积与圆切线、根式驻点及上方区域、斜边水槽优化。

分步数量：1步177个，2步429个，3步131个，4步14个，5步4个。一步小问多为直接读值、单次代入或简短结论；复杂题保留自然推理长度。

## 措辞变化示例

- P2-C03-R03(a)：由“State the permitted values of x in [equation]”改为标准的“State the range of values of x for which [log expression] is defined.”
- P2-C06-R01(c)：由“How many solutions would there be...”改为“State the number of solutions in the interval ...”。
- P2-C04-R14(a)：由“Using factorial expressions for the two coefficients...”改为“By expressing the two coefficients in factorial form...”。
- P2-C06-R15(a)：移除学生所有格的多余转义，并使用“may omit some solutions”。
- P2-C08-R18(c)：保留总竖直路程的数学含义，写为“A point moves along the curve ... Find the total vertical distance travelled by the point.”，避免不熟悉的长句。

## 核查

- 全245题的非新增内容比对通过；所有答案、数值、题干条件、分值与来源未改动，仅14处列明的设问语言变化。
- 755个叶子小问均有非空中文方法与有序实质步骤。
- 对新字段中2074处公式使用项目实际KaTeX库检查，全部可渲染；新增字符串无非法控制字符、无双重TeX转义。
- 手工补写步骤的关键式已复算：对数域及根、梯形I=1.7295及变形面积、多个区间符号、平方量优化导数、分段面积、切线斜率等。
- 本轮重点是解释与措辞，不声称重新独立求解全部245题，也不声称外部教师审定。保留已核查题库的数学答案，避免为扩写而引入新结论。

## 独立复核后的方法说明修订

独立复核指出四处重要小问的方法说明过于笼统。随后逐项检查并替换了全部57处后备方法说明，为每题补写针对实际条件与目标的中文策略，包括有向积分与总面积的区别、两条梯形的0/2/4横坐标、联立曲线直线找交点、平方量优化、阈值及单位换算等。原答案和分步计算未改动。
